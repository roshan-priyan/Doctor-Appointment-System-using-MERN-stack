# Doctor Appointment System (MERN Stack)

A full-stack web application built using MongoDB, Express.js, React.js, and Node.js to provide a user-friendly and efficient system for managing doctor appointments.

## 🚀 Features

**For Patients:**
* Search for doctors by specialty, location, or availability.
* Book, view, and manage appointments.
* Update personal profile information.

**For Doctors:**
* Manage schedules and availability dynamically.
* View patient information prior to consultations.
* Update appointment statuses (Confirm, Reschedule, Complete).

## 🛠️ Tech Stack
* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
